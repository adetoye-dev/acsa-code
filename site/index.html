What makes it different

  • Pay for tokens, not a subscription

    A local model is free. So are the free tiers. The ledger says what each turn cost, per provider — including what running locally saved you.

  • It stops instead of spinning

    A turn has a wall-clock ceiling. A provider that keeps failing is named and dropped. A run that changed nothing says so.

  • It remembers the project

    Files, symbols and dependencies are indexed on this machine, and decisions are written down where the next session finds them.

  • Any model you like

    Eleven providers, any OpenAI-compatible endpoint, or Ollama on this machine. Anthropic's API is the one exception, in agent mode.

How it goes

  1. Open a folder

    Projects are folders on disk. No import, no account.

  2. Say what you want

    Ask in chat, or switch to Agent and hand it the task.

  3. Keep the diff, or undo the turn

    Review it, stage it, commit it — or put the whole turn back.

Before you download

What it does not do

  • macOS 11 or newer. Windows and Linux are written for, not shipped.
  • A local model often cannot drive the agent — use a hosted provider for those runs.
  • Anthropic's API is not supported in agent mode.
  • Undo covers the turn that just finished, and only the files it touched.

Questions

What does it cost?

The app is MIT licensed and free. You pay the provider for tokens — or nothing at all with a local model. Groq, Google and NVIDIA have free tiers that need no card.

Do I need Python, Node or Codex installed?

No. The engine and the agent runtime are inside the app bundle.

Where do my keys go?

The operating system keychain. The app can set or clear one and ask whether it exists, never read it back.

Does my code leave my machine?

Only to the model you chose, as part of the prompts you send. With a local model, nothing leaves. There is no analytics SDK to opt out of.
